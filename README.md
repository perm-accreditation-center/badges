# Генератор бейджей аккредитации

Положите полученные документы СПО формата `.docx` в папку `input` и запустите `badge-generator.exe`.

Программа создаёт новый Word-файл в `output`. Исходные файлы не изменяются. После завершения терминал покажет количество обработанных записей, путь к результату и будет ждать Enter, чтобы окно не закрылось сразу.

Перед печатью в Word выберите бумагу A4 и «Фактический размер / 100 %». Не используйте «Подогнать к странице»: это изменит размер бейджей 90×55 мм.
